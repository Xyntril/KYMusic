# KYMusic Roadmap

Актуальный план развития проекта **KYMusic** — нативного клиента Яндекс Музыки для среды рабочего стола KDE Plasma и Plasma Mobile.

Репозиторий: [https://github.com/Xyntril/KYMusic](https://github.com/Xyntril/KYMusic)

---

## Выпущенные релизы

### v1.0.0 — Первый официальный релиз (KDE Plasma & Plasma Mobile)

Первый крупный стабильный релиз, знаменующий полный переход на архитектуру KDE Frameworks 6 и конвергентный дизайн:

#### 1. Системная интеграция KDE Plasma
- [x] **KDE Frameworks 6**: использование `Kirigami`, `KColorScheme`, `KXmlGui`, `KStatusNotifierItem`, `KIconThemes`.
- [x] **Нативный стиль**: 100% поддержка системных тем KDE Plasma (`Breeze`, `Breeze Dark`, `Oxygen`, `Fusion`, `Union`) и автоматическое следование системной палитре `KColorScheme`.
- [x] **Системный трей**: нативная плашка трея через `KStatusNotifierItem` с быстрым управлением треками, паузой, громкостью и отображением обложки.
- [x] **Глобальное меню и меню окна**: интеграция с Global Menu по D-Bus (`appmenu`), нативная строка меню `MenuBar` (`Ctrl+M`) и адаптивное `KHamburgerMenu`.
- [x] **Системные диалоги**: окна «О программе KYMusic» и «О среде KDE» на базе `KF6::XmlGui` (`KAboutData`, `KAboutApplicationDialog`).

#### 2. Двусторонняя интеграция MPRIS2 D-Bus
- [x] **Стандарт `org.mpris.MediaPlayer2.Player`**: полная реализация всех методов управления (`Play`, `Pause`, `PlayPause`, `Next`, `Previous`, `Seek`, `SetPosition`, `Stop`).
- [x] **Двусторонняя синхронизация**: сигналы `PropertiesChanged` для `PlaybackStatus`, `LoopStatus` (`None` / `Track` / `Playlist`), `Shuffle` и метаданных.
- [x] **Плавный повтор и кроссфейд**: исключён ложный переход в `Stopped` при повторе трека (`RepeatOne`) или переключении аудио-слотов кроссфейда; корректный сигнал `Seeked(0)`.
- [x] **Уникальный сервис**: поддержка нескольких копий и fallback-имя экземпляра по PID.

#### 3. Конвергентность и KDE Plasma Mobile
- [x] **Автоматический мобильный режим**: адаптация компоновки под ширину экрана и сенсорные экраны Plasma Mobile.
- [x] **Мобильные шапки**: страницы Альбома, Исполнителя и Плейлиста переходят в центрированный вертикальный `ColumnLayout` с крупной обложкой 150×150 и переносящимися рядами кнопок без обрезания.
- [x] **Сенсорная навигация**: нижняя панель навигации `NavigationTabBar`, всплывающее меню разделов в шапке и удобная кнопка «Назад».
- [x] **Мобильный мини-бар**: компактный плеер высотой 56px с индикатором прогресса и быстрым доступом к полноэкранному плееру.
- [x] **Адаптивные настройки**: аккуратный перенос текста чекбоксов (`WordWrap`), скрытие чисто десктопных опций на мобильных устройствах.

#### 4. Воспроизведение и визуальные эффекты
- [x] **Ambient Glow**: настраиваемая атмосферная подсветка фона на основе цветовой гаммы обложки текущего трека.
- [x] **Мини-плеер**: компактное плавающее окно поверх всех окон для многозадачной работы (включая Wayland).
- [x] **Развёрнутый полноэкранный плеер**: тексты песен, очередь, похожие треки, управление качеством и громкостью.
- [x] **Синхронизированные тексты песен**: поддержка LRC с подсветкой активной строки и фолбэком на LRCLIB.
- [x] **Управление качеством**: выбор от низкого до Lossless (FLAC) с индикацией кодека и битрейта.
- [x] **Плавный переход (Crossfade)**: настраиваемое затухание от 0 до 15 секунд между треками.

#### 5. Каталог и функциональность Яндекс Музыки
- [x] «Моя волна», персональные рекомендации, подборки и персональные плейлисты.
- [x] Полный поиск с подсказками, историей недавних запросов и центрированной заглушкой.
- [x] Управление личной медиатекой: создание, редактирование и удаление плейлистов, лайки треков, альбомов и артистов.
- [x] Раздел «Статистика»: графики минут по дням, любимые треки и артисты.
- [x] Разделы «Станции», «Новые релизы», «Жанры» и «Подкасты».
- [x] Скачивание треков с тегами ID3v2 и обложкой через TagLib.
- [x] Фильтрация AI-треков (база Slopless) и подмена цензурированных дорожек (FckCensorData).

## Планы на будущие версии

### v1.1.0 — Портативность и расширенный контент

- [ ] **Android (APK)**: сборка мобильного пакета для Android на базе Qt 6 и Kirigami.
- [ ] **Офлайн-режим медиатеки**: скачивание целых плейлистов и альбомов в локальный кэш для прослушивания без сети.
- [ ] **Аудиокниги**: специализированный раздел каталога с сохранением прогресса по главам и таймером сна.
- [ ] **Подкасты 2.0**: подписки на подкасты, уведомления о новых выпусках и регулировка скорости речи (0.75x–2.0x).
- [ ] **Виджет рабочего стола Plasmoid**: нативный виджет для KDE Plasma 6 для панели задач и рабочего стола.

### v1.2.0 — Экосистема и стриминг

- [ ] **Трансляция аудио**: поддержка вывода звука через PipeWire / PulseAudio Network Sinks и DLNA / Chromecast.
- [ ] **Scrobbling**: интеграция с Last.fm и ListenBrainz.
- [ ] **Сквозная синхронизация очередей (Ynison)**: передача текущего контекста воспроизведения между устройствами.
